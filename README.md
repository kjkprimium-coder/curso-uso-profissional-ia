# Uso Profissional de IA — V0.2 funcional (pacote para celular)

## Estrutura EXATA

```text
curso-uso-profissional-ia-v0.2-mobile/
├── index.html
├── style.css
├── app.js
├── .nojekyll
└── README.md
```

**Todos os arquivos principais ficam na raiz.** Não crie pastas `css` ou `js` para esta versão.

## Como colocar no GitHub pelo celular

1. Abra o repositório `curso-uso-profissional-ia`.
2. Apague os arquivos antigos do site.
3. Envie os cinco arquivos deste pacote para a raiz do repositório.
4. Confira se `index.html`, `style.css` e `app.js` aparecem no mesmo nível.
5. Vá em Settings → Pages.
6. Em Build and deployment, use `Deploy from a branch`.
7. Branch: `main` e pasta: `/ (root)`.
8. Salve.
9. Aguarde a publicação e abra o endereço do curso.

## O que já funciona

- Página inicial do curso.
- 8 módulos.
- 20 aulas.
- Navegação por módulos e aulas.
- Progresso local salvo no dispositivo.
- Estrutura pedagógica de cada aula.
- Plano de validação.
- Área audiovisual preparada para a produção posterior.
- Layout responsivo para celular.

## Importante

Esta é uma V0.2 funcional para visualização, demonstração e teste pedagógico. O conteúdo final e o audiovisual definitivo serão refinados depois de testarmos com um iniciante.

Se a aparência ficar novamente sem estilo, a primeira coisa a conferir é se `style.css` está na raiz ao lado de `index.html`. O `index.html` desta versão usa `./style.css` e `./app.js`.
