# Uso Profissional de IA — V0.2 funcional (mobile)

## Estrutura obrigatória

Todos os arquivos ficam diretamente na raiz do repositório:

- index.html
- style.css
- app.js
- .nojekyll
- README.md

Não coloque `style.css` ou `app.js` dentro de pastas.

## O que foi corrigido

Esta versão usa uma estrutura simples e compatível com GitHub Pages. O `index.html` carrega `./style.css` e `./app.js`, e o JavaScript não depende de elementos HTML que não existem.

## Conteúdo

- 8 módulos
- 20 aulas
- progressão por níveis
- desafios, conceitos, demonstração, prática, conferência, aplicação e síntese
- navegação por aula e módulo
- progresso local no dispositivo
- plano de validação
- espaço audiovisual preparado

## Publicação pelo celular

Na raiz do repositório, deixe exatamente os cinco arquivos acima. O GitHub Pages deve publicar `main` e `/(root)`.
