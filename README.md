# Uso Profissional de IA — V0.1

Protótipo navegável do Curso 1.

## Objetivo

Validar a experiência do curso antes da produção definitiva de conteúdo e vídeos.

## Stack

- HTML
- CSS
- JavaScript puro
- LocalStorage para progresso
- Preparado para GitHub Pages

## Estrutura

- `index.html` — entrada da aplicação
- `css/style.css` — identidade e responsividade
- `js/app.js` — dados do curso, rotas, navegação e progresso
- `assets/` — espaço para imagens, vídeos e demais mídias

## Publicação

O projeto é estático e pode ser publicado pelo GitHub Pages sem servidor.

## Próxima etapa

Após testar a V0.1, revisar UX e currículo. Em seguida, substituir placeholders por conteúdo, exercícios, materiais e vídeos definitivos.
